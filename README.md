# 疯狂渔场 · 网页构筑原型

**在线试玩：<https://uoghluvm.github.io/crazy-fishery/>**（由 `mvp.html` 自动发布到 GitHub Pages；存档保存在你自己的浏览器里）。

也可以直接用浏览器打开 `mvp.html`，无需安装依赖、无需启动服务。首次打开会出现玩法说明，选择「开始五日冒险」即可玩一局，也可选择原来的「自由构筑」。

## 怎么玩一局

1. 打开 `mvp.html`，点「开始五日冒险」。初始船体 100，木材 18，自带两座弩炮、弹药架和捕鱼网。
2. 点「建造」，选弩炮，再点中心弹药架右边或下边的空甲板。相邻攻击建筑吃到 +5。
3. 点「海域地图」。比较浅海和险航的敌人、预计船损与奖励；不满意可返回整备。
4. 观看海怪与木筏逐轮交锋；可点「跳过动画」直接查看结果。存活后领取木材，再建造、修船或扩建。
5. 第五天击败巨兽且船体仍大于 0 就通关；船体归零失败，可以立即重开。

建议先补火力，再考虑护盾。捕鱼网决定后续收入，不必为了攻击把所有资源建筑都拆掉。出航预报会明确标记会沉没的选择。

## 本轮试验规则

这些参数用于验证可玩循环，不改写设定文档中的待定事项。

- 自动战斗：双方每轮同时攻击；攻击取已放置建筑的最终值之和，悬停预览不参战。
- 护盾塔的最终值每轮减伤，每轮至少损失 1 船体。没有攻击时直接沉没。
- 每次胜利获取基础 8 木材；险航基础 16；两者都额外加上资源建筑的最终产出。
- 建筑费用：弩炮 8、鱼叉 5、捕鱼网 6、净化器 5、弹药架 8、灯塔 14、珊瑚礁 12、护盾塔 10。
- 拆除全额返还；覆盖已有建筑时只支付差价。木材不足不会扣款或放置。
- 扩建到 4×4 花 15，到 5×5 花 25；每次修船花 10，恢复 25 船体，上限 100。
- 自由构筑仍免费，可用预设和清空。冒险隐藏这两个操作，避免绕过经济规则。
- 冒险会自动保存，刷新后可选择「继续上次冒险」。开始新冒险会覆盖旧局；自由构筑不覆盖冒险存档。

## 操作

- 底部「建造」打开建筑抽屉，选定后点击甲板放置；可连续放置，再选建筑可覆盖。
- 悬停或用 Tab 聚焦甲板，查看结算浮层、真实作用目标的底色和连线。
- 「拆除」切换点击拆除模式；也可右键拆除，键盘聚焦后 Delete / Backspace 拆除。
- Esc 退出建造或拆除模式。未选择建筑时点击仅查看，不会删除。
- 「扩建」依次增加到 4×4、5×5，保留建筑，到上限禁用。
- 自由构筑中「灯塔阵」「珊瑚场」会替换当前布局；「清空」删除当前布局。
- 建造抽屉可关闭音效；动画遵循系统的“减少动态效果”。

## 本轮修改（2026-11-15）

依据界面美术与体验要求，改造网页表现层：海平线、多层海水与漂移波纹、菱形木质甲板及厚度、八种 SVG 建筑、投影、漂浮数值、非同步晃动、底部抽屉及悬停算式。加入落位、下沉、数值飘字、木屑/水花、拆除和短音效。

位置规则保持 `(基础 + 固定加成) × 倍率`。结算与关系显示共用目标过滤，修正弹药架对资源建筑的错误来源提示；倍率不再按一位小数误报。修复扩建循环缩回及未选建筑时点击误删。网页无新增运行依赖。`prototype/` 的 Godot 版本尚未同步此次改造。

## 海图、移动海怪与无限金币商店

- 「海域地图」展示 5 天航线：每天两个战斗节点，第五天汇合到巨兽。只允许选择当前天数的节点；已走路线显示绿色。选节点前可查看下方对应的船损预报。当前地图是航线选择图，不是自由操控木筏的开放世界。
- 海怪从远处接近，回合间游向侧翼，移动结束后再发起齐射。炮弹使用当轮实际位置，移动不改变原有伤害规则。跳过或减少动态效果仍得到相同结果。
- 底部「招募商店」可单抽、十连或直接购买指定建筑。标价使用**无限测试金币**，不会接入真实支付或扣款。
- 单抽标价 100、十连 1,000 金币；普通 70%、稀有 25%、传奇 5%。同级建筑等概率。连续 19 次未获得传奇，第 20 次必出，提前获得传奇会重置计数。概率是非保底抽的基础概率。
- 普通池：弩炮、鱼叉、捕鱼网、净化器；稀有池：弹药架、护盾塔；传奇池：灯塔、珊瑚礁。稀有度标识池子分类，不额外修改建筑基础数值。
- 重复抽到的建筑累加到仓库。建造时优先免费消耗库存；没有库存时才按原规则花木材。已放置建筑不因打开商店而变化。
- 冒险中可花测试金币购买 100 木材，用于扩建和修船。金币无限，木材仍有具体余额；测试经济因此不用于判断正式难度。
- 冒险的仓库和保底随存档恢复；开始新冒险会重置。自由构筑的临时仓库不保存。

新增验证覆盖地图节点锁定与历史路线、连续 20 抽保底、重复库存、库存免费放置、无限金币购买物资。

## 随机海图与道具图鉴

- **随机海图**：每次「开始五日冒险」都会按一个编号（1–999999）生成新航线网。每天的节点数固定为 2/3/3/2/1，第 5 天只有巨兽；每个节点都有来路和去路，每天至少一条巡游，第 2、3 天至少有一天出现补给。同一天的巡游/险航还会换不同的海怪组合，所以不再每局都遇到同样的敌人。
- 海图编号显示在航线图下方。用 `mvp.html?seed=编号` 打开可以复现同一张图（只对载入后的第一局冒险生效）。存档只记编号，继续冒险时重新生成同一张图；路线按存档自己的海图校验。没有编号的旧存档仍使用原来的固定海图。自由构筑不受影响。
- **道具图鉴**：右下角「图鉴」按钮。「建筑」页列出全部 14 种建筑的数值、位置效果、费用和来源，标出“本局持有 / 已收集 / 未收集”；「宝藏」页在获得前只显示“？？？”。收集记录跨局保留，单独存放在浏览器的 `crazy-fishery.codex.v1`，不进冒险存档，损坏时自动忽略。战斗动画和弹窗期间不能打开。
- 新增检查 `python test_map_codex.py`：1500 个编号的结构保证与确定性、5 张海图经界面从第 1 天打到巨兽、同编号续档得到同一张图、伪造/越界编号被拒绝、旧存档兼容、图鉴收集与持久化、桌面与窄屏截图。
- `test_mvp.py` 与 `test_save.py` 已按现在的航线图流程更新：点船票出航、三选一战利品、补给节点；通关用固定海图 #4242，随机的战利品不影响断言。三份测试共用 `ui_helpers.py`。
