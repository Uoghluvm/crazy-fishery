# 《疯狂渔场》木筏构筑原型 v0.1

只验证一件事：**建筑摆在哪，值不值得反复琢磨。**

不含战斗、不含资源消耗、不含航线推进。

---

## 如何运行

本机还没装 Godot，需要先装（免费，约 120 MB）：

1. 下载 **Godot 4.4 或更高版本的 Standard 版**（不要 .NET 版）
   https://godotengine.org/download/windows/
2. 解压得到 `Godot_v4.x-stable_win64.exe`，双击打开
3. 在项目管理器点 **导入（Import）**，选中本文件夹里的 `project.godot`
4. 打开后按 **F5** 运行（或点右上角 ▶）

> 界面用的是系统里的微软雅黑字体。Godot 自带字体不含中文字形，代码里已自动挂载字体，若换机器没中文字体会在控制台给出警告。

## 操作

| 操作 | 效果 |
|---|---|
| 左侧点击建筑 | 选中（再点一次取消选中） |
| 选中后点击格子 | 放置建筑 |
| 右键点击格子 | 拆除 |
| 悬停任意格子 | 实时结算 + 高亮影响关系 |
| 「灯塔弩炮阵 / 珊瑚渔场」 | 一键铺一个已知组合，用来对比手感 |
| 「清空木筏」 | 重置 |

## 界面读法

- **金色粗边** = 当前悬停的格子
- **青色粗边** = 与它存在影响关系的格子（它影响的 + 影响它的，一起高亮）
- 大数字 = 该建筑**结算后的最终值**；金色代表被强化，红色代表被削弱
- 数字下方小字 = 加成来源（如 `+5 ×1.5`）
- 底部信息栏 = 这一格的完整算式与受谁影响

## 已实现的建筑与效果

| 建筑 | 类 | 基础 | 位置效果 |
|---|---|---|---|
| 弩炮 | 攻击 | 10 | — |
| 鱼叉 | 攻击 | 6 | — |
| 捕鱼网 | 资源 | 5 | — |
| 海水净化器 | 资源 | 4 | — |
| 弹药架 | 技能 | — | 相邻（上下左右）**攻击**建筑 +5 |
| 灯塔 | 奇妙 | — | 相邻（上下左右）建筑 ×1.5 |
| 珊瑚礁 | 奇妙 | 3 | 周围 3×3（含斜向）其他建筑 +2 |
| 护盾塔 | 技能 | 3 | — |

结算顺序：`(基础 + 固定加成) × 倍率`。已铺的组合会立刻显示下一格能吃到多少。

## 试玩时重点看什么

带这几个问题去点，比随便摆更能判断值不值：

1. **放下一个建筑时，你有没有犹豫？** 如果 9 格随便摆都差不多，说明位置效果不够狠。
2. **有没有出现"我想把某个已放好的建筑挪走"的冲动？** 有，说明组合有张力——但如果你找不到地方挪（没有拆除/重排机制），说明需要一键重排。
3. **灯塔放中间 vs 放角落，差别够不够明显？** 现在中间能强化 4 格、角落只能强化 2 格，这是目前唯一的"位置博弈"。
4. **3×3 是不是太小？** 只有 9 格时，往往摆两三个建筑就满了，"组合"还没开始就结束。这是我最担心的一点。
5. **奇妙型建筑够不够"奇妙"？** 现在灯塔和珊瑚礁只是数值加成，严格说不算奇妙型，真正的奇妙型应该改变规则。

## 已知取舍（刻意没做）

- 战斗、敌人、资源消耗一律没有——加了就没法单独判断"摆放"这一层
- 建筑不可拖动，只能拆了重放
- 数字是硬编码在 `board.gd` 的 `_build_catalog()` 里，改数值直接改那里
- 效果只有 3 种（相邻固定加成 / 相邻倍率 / 范围固定加成），加新效果在 `_compute()` 里加一个 `match` 分支

## 文件结构

```
prototype/
├─ project.godot          工程配置
├─ main.tscn              主场景（只有一个挂脚本的根节点，UI 全部由代码生成）
└─ scripts/
   ├─ building_data.gd    建筑数据结构（Resource）
   └─ board.gd            格盘、放置、效果结算、界面
```

UI 全部用代码搭，没用手写 .tscn —— 原型阶段改起来比在编辑器里拖快，也避免手写场景文件的格式坑。正式版应该改成编辑器里搭。
